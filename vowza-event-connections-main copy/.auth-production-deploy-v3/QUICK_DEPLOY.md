# 🚀 Quick Deploy Your Vowza Platform

## Option 1: Netlify (Easiest - 2 minutes)

### Step 1: Go to Netlify
1. Open **https://app.netlify.com/drop**
2. You don't need to sign up for this quick deploy

### Step 2: Upload Your Files
1. **Drag and drop** the entire `dist` folder into the browser
2. Wait for upload to complete (30 seconds)
3. **Copy your live link** (looks like `random-name-123456.netlify.app`)

### Step 3: Done! 🎉
Your platform is now live with a shareable link!

## Option 2: GitHub Pages (Free & Permanent)

### Step 1: Push to GitHub
```bash
git init
git add .
git commit -m "Deploy Vowza Event Platform"
git branch -M main
git remote add origin https://github.com/yourusername/vowza-platform.git
git push -u origin main
```

### Step 2: Enable GitHub Pages
1. Go to your repository on GitHub
2. Click **Settings** → **Pages**
3. Select **Deploy from a branch**
4. Choose **main** branch and **/(root)** folder
5. Click **Save**
6. Wait 2-3 minutes
7. Your site will be live at `https://yourusername.github.io/vowza-platform`

---

## Option 3: Vercel (Professional)

### Step 1: Go to Vercel
1. Open **https://vercel.com**
2. Click **"New Project"**
3. Import your GitHub repo or upload files

### Step 2: Configure
1. Framework preset: **Other**
2. Build command: Leave empty (already built)
3. Output directory: `dist`
4. Click **Deploy**

### Step 3: Get Your Link
Your platform will be live at `https://your-project-name.vercel.app`

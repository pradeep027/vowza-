COMMON ISSUES & FIXES
================================================================================

ISSUE: Homepage shows blank promotion cards
FIX:   1. Publish promotion in admin
       2. Hard refresh page (Ctrl+F5)
       3. Check console for errors

ISSUE: Admin selector shows no vendors
FIX:   1. Check vendors exist for category
       2. Verify vendor profession matches category
       3. Ensure vendors not deleted

ISSUE: Booking doesn't save correct IDs
FIX:   1. Verify migration applied
       2. Check database schema has columns
       3. Inspect network request payload

ISSUE: Package not pre-selected
FIX:   1. Check URL has ?package={id}
       2. Verify package ID exists
       3. Refresh page (browser cache)

ISSUE: Vite HMR errors
FIX:   1. npm run dev --host
       2. Clear node_modules cache
       3. Restart dev server

================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: Can't access localhost
FIX:   1. Check dev server running: npm run dev
       2. Try: http://localhost:8080 (not 127.0.0.1)
       3. Check: Port 8080 is not blocked

ISSUE: Admin selector shows no vendors
FIX:   1. Verify vendors exist in database
       2. Check vendor profession = category
       3. Select different category

ISSUE: Homepage shows blank promotions
FIX:   1. Publish promotion (click "Publish" button)
       2. Hard refresh: Ctrl+F5
       3. Check console for errors: F12

ISSUE: Package not pre-selected
FIX:   1. Check URL has ?package={id}
       2. Verify package ID is real UUID
       3. Check browser console: F12 → Console

ISSUE: Booking doesn't have correct IDs
FIX:   1. Check migration applied
       2. Verify database columns exist
       3. Check network request in DevTools
